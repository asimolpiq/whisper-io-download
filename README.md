# WhisperIO

## Türkçe

WhisperIO, düşük kaynak tüketimi odaklı bir masaüstü sesli iletişim uygulamasıdır.
Oda kodu ile hızlıca oda oluşturup katılımcılarla sesli iletişim kurmanızı sağlar.

### Öne Çıkan Özellikler
- Düşük kaynak kullanımı odaklı performans
- Oda kodu ile hızlı oda oluşturma ve katılma
- Host kontrolü: kullanıcı atma ve odayı silme
- Gürültü bastırma seçeneği
- Katılımcı bazlı ses seviyesi ayarı
- İngilizce dil desteği

## English

WhisperIO is a lightweight desktop voice communication app designed for low resource usage.
It lets you quickly create or join rooms with a room code and communicate by voice.

### Key Features
- Performance focused on low resource usage
- Fast room creation and joining with room codes
- Host controls: kick users and delete room
- Optional noise suppression
- Per-participant volume control
- English language support
